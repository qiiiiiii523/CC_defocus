## 2. A0 定义与 A0-v1 固定配置

**A0 定义：仅用模糊 RGB 图作为空间条件的基础恢复模型。**不包含退化估计条件、PSF 重模糊损失、核掩膜/边界监督或细胞学特征监督。

**A0-v1：当前改造后的 JiT-B/16，从随机初始化开始，在 66,976 对训练样本上训练 20 轮；Flow + Charbonnier（权重 1），10% 恒等训练；评价选择 EMA2，使用一步 Euler 推理、eval_seed=0。**

训练配置和推理配置分开保存：原训练过程中采用 Heun 50 步验证；训练完成后的采样对照选择了一步推理。没有为一步推理重新训练或蒸馏。

## 3. 网络输入与输出

记清晰目标为 x，模糊输入为 y，噪声为 e，当前生成状态为 z_t。

| 信息 | 形状/范围 | 用途 |
|---|---|---|
| 模糊图 y | `[B,3,256,256]`；公共 RGB `[0,1]`，网络内部 `[-1,1]` | 空间图像条件 |
| 当前状态 z_t | `[B,3,256,256]`；无强制范围截断 | 网络待更新的生成状态 |
| 时间 t | 每样本一个标量，位于 `(0,1)`；推理可用 t=0 | 时间条件 |
| null 类别索引 | `[B]`，当前固定为 1000 | 保留原类别嵌入接口，不输入细胞类别或文本 |
| 清晰目标 x | 与 y 对齐 | 训练构造状态、计算监督；推理不能输入 |
| 网络清晰终点预测 x_hat | `[B,3,256,256]`；原始输出不强制截断 | 换算速度、计算损失或一步返回 |
| 保存的恢复图 | RGB `[0,1]` PNG | 由内部输出反归一化并裁剪后保存 |

`model_jit.py` 的形参 `y` 是旧的类别索引接口，不是本说明的模糊图 y。代码中的模糊图通过 `blur=` 传入。

## 4. 当前网络结构

```text
当前状态 z_t                         模糊图 y
    │                                    │
状态 patch 编码器                    独立模糊条件编码器
Conv 3→128，kernel=16，stride=16      Conv 3→128，kernel=16，stride=16
Conv 128→768，kernel=1               Conv 128→768，kernel=1
    │                                    │
256 个 768 维 token                 256 个 768 维 token
    │                                    │
固定二维 sin/cos 位置编码            RMSNorm → Linear(768,768)
    │                                    │
    │                                 tanh(gate) × 特征
    └────────────────── 按空间位置相加 ──┘
                              │
                  12 层 JiT Transformer
                  hidden=768；12 个注意力头
                  时间嵌入 + null 类别嵌入调制
                              │
                  最终调制层及线性 patch 输出
                              │
                   unpatchify → x_hat
```

### 4.1 模糊图编码器是什么？

实现类为 `BlurConditionEncoder`，不是文本编码器、DINO、UniCAS 或 Smart-CCS。

- 与状态编码器一样使用 `BottleneckPatchEmbed`。
- 256×256 图像划分成 16×16 个 patch，共 256 个空间 token。
- 两个卷积之间没有额外非线性激活；patch 的 RGB 信息先压到 128 维，再映射到 768 维。
- 条件适配器是 RMSNorm 加一个 Linear(768,768)。
- 使用可训练标量 gate，经 tanh 后控制条件残差强度；不是逐像素模糊程度图，也不是必须位于 `[0,1]` 的概率。
- scratch 初始化时，把随机初始化状态编码器的参数数值复制给模糊分支；两个分支参数独立，后续分别更新。没有使用官方预训练权重。

### 4.2 条件怎么注入？

当前实现是：

```python
tokens = x_embedder(z_t) + pos_embed
tokens = tokens + blur_condition_encoder(blur)
```

即在 Transformer 入口进行一次按空间位置对齐的加法融合。每次网络调用都重新传入同一张模糊图，因此多步采样的每个网络调用都能看到条件；**并不是在每个 Transformer block 单独再次注入条件。**

### 4.3 保留的 JiT 主干

- JiT-B/16：12 层，隐藏维度 768，12 头注意力。
- 时间嵌入、保留的类别嵌入表及 adaLN 调制接口。
- 从零基索引 block 4（第 5 层）起加入 32 个 in-context token，期间序列长为 288；输出前移除这些 token。
- Transformer 内部注意力/FFN 残差、位置编码、RoPE、线性 patch 输出及 unpatchify。
- 当前没有图像级 `x_hat = y + delta` 残差输出，也没有高分辨率 CNN 跳连解码器。
- 主干及新增条件分支都参与训练；固定 sin/cos 位置编码不更新。没有使用 LoRA 或仅训练新增分支的方案。
- 保留类别表不代表这是文本条件模型；scratch 路线下该表同样随机初始化，null 行是可学习参数。

## 5. 训练方法与损失

### 5.1 配对条件 flow 训练

时间采样采用 logistic-normal：

\[
t=\operatorname{sigmoid}(u),\qquad u\sim\mathcal N(-0.8,0.8^2).
\]

噪声 e 为 noise_scale=1 的高斯噪声，构造：

\[
z_t=t x+(1-t)e,\qquad \hat x_t=f_\theta(z_t,t,y).
\]

训练直接采样一个 t 并做一次网络预测，**不是每个训练 batch 都跑完整 50 步生成**。

当前代码含分母下限，准确损失写法为：

\[
d_t=\max(1-t,0.05),\quad
v=\frac{x-z_t}{d_t},\quad
\hat v=\frac{\hat x_t-z_t}{d_t},
\]

\[
L_{\rm flow}=\operatorname{mean}\big[(v-\hat v)^2\big]
=\operatorname{mean}\left[\frac{(x-\hat x_t)^2}{d_t^2}\right].
\]

未触发下限时，目标速度等于 x-e；触发下限后，不应把代码目标速度一概写成 x-e。

### 5.2 Charbonnier 像素损失

```python
difference = (prediction.float() - target.float()) * 0.5
loss_charb = sqrt(difference**2 + eps**2).mean()
loss = loss_flow + lambda_pix * loss_charb
```

\[
L_{\rm Charb}=\operatorname{mean}\sqrt{\left(\frac{\hat x_t-x}{2}\right)^2+10^{-6}},
\qquad L=L_{\rm flow}+1.0\,L_{\rm Charb}.
\]

除以 2 是把内部 `[-1,1]` 的差值转换到公共 RGB `[0,1]` 差值尺度。像素损失用 FP32 运算，不先裁剪预测，没有额外 flow 时间权重。

lambda_pix=1 只是损失系数，不意味着两项梯度贡献相同。A0-v1 未额外加入 SSIM loss、PSNR loss、PSF loss 或核/特征 loss。

### 5.3 10% 恒等训练

每次取得训练样本时，以 0.10 的概率把模糊条件替换成该样本清晰图的副本，目标仍是同一张清晰图。它是样本替换概率，不是 loss 权重，也不是额外增加固定 10% 的样本文件。

训练中模糊和清晰图同步随机裁剪、同步水平翻转。验证不做随机增强、不替换恒等样本、不自动缩放图像。清晰目标和人工核标注不能作为推理输入。

## 7. 固定的一步推理与评价

网络从噪声 z_0=e 出发，t=0 时预测 x_hat_0，Euler 步长为 1：

\[
z_1=z_0+\frac{\hat x_0-z_0}{1}=\hat x_0.
\]

因此一步输出等价于 t=0 的清晰终点预测。这仍是 flow + 像素监督训练得到的网络，但不能声称已经准确求解完整生成轨迹或完成单步蒸馏。

| 推理项 | 固定值 |
|---|---|
| 权重来源 | checkpoint 的 `model_ema2` |
| sampling_method / num_sampling_steps | euler / 1 |
| eval_seed / seed | 0 / 0 |
| noise_scale / t_eps | 1 / 0.05 |
| amp_bf16 / eval_batch_size | true / 4 |
| 输入输出尺寸 | RGB 256×256 |
| 保存 | 内部输出转为 RGB `[0,1]`，裁剪、保存 PNG |
| 指标 | 主要 PSNR、SSIM；RGB，data_range=1，crop_border=0，不 resize |

初始噪声由 eval_seed 和 sample_id 的 SHA256 派生种子产生，不依赖评估顺序或 batch 划分。seed0 为预先选定的固定默认值，不能根据答案逐图选种子。

此前一步实验标签为 Heun，但当前代码的一步分支只执行最后一次 Euler；这里明确记录为 Euler。

## 11. 后续实验如何不破坏 A0-v1

- 永远不把新的训练 output_dir 设为 `a0_v1_frozen`。
- 改编码器、条件注入、残差路径或损失，另开实验名与分支；确认有效后再定为 A0-v2。
- 仅延长当前结构训练，称 A0-v1-continued/longer，保留原 20 轮权重。
- 仅改推理步数/采样器，记录为 A0-v1 的另一推理配置，不声称重新训练了网络。
- A1 从同一 A0-v1 基础出发，与等额外训练预算的 A0-v1-continued 比较；数据、损失、一步推理与评价规则保持一致。
- 新分支新增网络层后，旧 checkpoint 不能直接无条件 strict resume；需单独设计加载已有层、新层初始化及优化器状态策略。
- 两组继续训练必须采用相同起始参数来源：普通权重或 EMA2 均可明确设计，但不能混用。**当前 `--resume` 默认恢复普通 model 权重与原 optimizer，`--eval_weights ema2` 只控制评价，不会把训练起点切换成 EMA2。**
- 新分支允许继续研究；旧代码、旧 checkpoint、旧结果与 A0-v1 说明必须保留。固定基线不等于冻结主干参数。
