# K0：从同一A0起点做CNSeg核监督对照

分支：`jit-k0`，从 `jit-a0-scratch` 创建。不改变JiT网络参数键、噪声路径或推理输入，不接入A1。

## 交接与实验边界

B交付的是普通核区域/边界带像素L1及其梯度检查，不是训练完成的K0。不是分割Dice、形状监督或逐核平衡。边界使用4邻域内侧一像素，图外不作为背景。

两组从同一个已训练A0 checkpoint、同一种权重开始，在同批CNSeg上重新建立适配实验。不要直接与仅用3DHistech训练的A0相比较来归因核损失。

服务器候选起点：`/home/qht/大创/CC_defocus/checkpoints/jit_a0_scratch_full66976_charb1_e20/checkpoint-last.pth`。
本地未读取它；启动前核对checkpoint版本、采样设置与代码匹配。普通/EMA起点由双方冻结；默认普通权重。

## 数据协议

`--dataset_mode cnseg`使用`dataset_cnseg.py`，筛选原清单的train/val及quality_status=pass，保留test不使用。
字段：sample_id、split、group_id、clear_path、instance_mask_path、degradation。
当前支持显式Gaussian/reflect合成：按清单kernel_size、sigma建立归一化离散核，全图卷积后裁图。这是新接入的明确实现，必须与B原合成程序核对，不能默认逐像素相同。

训练同步随机裁剪、水平翻转；验证固定中心裁剪，不缩放。清晰图、合成模糊图、实例mask始终对齐。
原图小于img_size时直接报错，不偷偷resize。实例mask必须是二维非负整数ID，背景0；不使用二值mask冒充实例。
同图不同severity可在同一split；跨split的原图/group重复直接拒绝。

本地清单存在，但首条对应 `prepared/masks/cnseg_patchseg/train/0000_0.png` 缺失。
B需交齐mask与数据，不能用全零mask绕过。

## 损失与初始化

训练在Denoiser当次`x_pred`上计算核监督，不在无梯度的generate()上计算。
RGB转换为 `(x_pred+1)/2`，不clamp、不detach，目标同样转换。
`L = L_flow + lambda_pix * L_charb + lambda_nucleus * (region_weight * L_region + boundary_weight * L_boundary)`。
日志分列核区域、边界和加权核项；无核对照lambda_nucleus=0，保持同份数据与代码。

`--init_checkpoint`只加载选定模型参数：优化器、EMA、epoch/global_step重新初始化；不会读取官方预训练权重。
`--resume`用于恢复本实验中断任务，保留优化器/EMA/epoch且核配置必须一致。两参数不能同时使用。
`--init_mode scratch`不等于K0重新随机初始化；使用init_checkpoint才是真正共同起点。

## 服务器操作模板（本地没有执行）

先交齐数据并运行CPU小测试，再GPU小批量检查。下面是配置模板，不是已验证的最佳超参数。

```bash
cd /home/qht/大创/CC_defocus/JiT
conda activate jit-a0
python check_nucleus_losses.py --output ../reports/k0_nucleus_loss_checks.json

# 两组共用配置，分别运行 lambda_nucleus=0 和经小批量校准的正权重。
CUDA_VISIBLE_DEVICES=0 python -u main_restoration.py \
  --dataset_mode cnseg \
  --train_manifest ../prepared/manifests/cnseg.jsonl \
  --val_manifest ../prepared/manifests/cnseg.jsonl \
  --expected_train_pairs 0 --expected_val_pairs 0 \
  --init_checkpoint ../checkpoints/jit_a0_scratch_full66976_charb1_e20/checkpoint-last.pth \
  --init_weights model --epochs 20 --batch_size 8 --lr 1e-5 \
  --warmup_epochs 2 --lr_schedule cosine --min_lr 1e-6 \
  --identity_ratio 0.1 --lambda_pix 1 --lambda_nucleus 0 \
  --nucleus_region_weight 1 --nucleus_boundary_weight 1 \
  --amp_bf16 --seed 0 --eval_seed 0 --eval_weights model \
  --sampling_method euler --num_sampling_steps 1 \
  --model_name cnseg_no_nucleus --output_dir ../checkpoints/cnseg_no_nucleus \
  --run_metrics
```

K0组只改lambda_nucleus、实验名、输出目录和所用GPU。不要改变seed、数据、采样或预算。
一阶Euler/1步仅作为基于既有结果的候选共同推理配置，双方需冻结。20轮和核权重都需小试确认。
正式推理使用同一CNSeg验证中心裁图；`evaluate_k0.py`自动写全图PSNR/SSIM/LPIPS、核区域/边界/背景RGB MAE及合成blur的不恢复基线。
空核指标为缺失值而非0，汇总带valid_count；不把区域MAE称为形状准确率。
这里评价的是CNSeg中心图块，不是原始全图，也不是3DHistech固定300对分数。
