# 成员 C：局部 A1 与 A2/A3 接口草案

> 状态：局部估计器已在 RTX 6000D 上训练并完成独立验证。具体结果、限制和交接路径见同目录的 `LOCAL_A1_A3_RESULTS.md`。

## 退化定义

局部估计器只读取一张模糊 RGB 图 `blur_01: float32 [B,3,H,W]`、范围 `[0,1]`；输出 `local_probabilities: float32 [B,3,ceil(H/4),ceil(W/4)]`。三通道依次是 `light/medium/heavy`，每个空间位置的概率非负、和为 1。它们分别对应现有的全局高斯核 `σ=1.0,K=7`、`2.0,13`、`3.5,23`，`reflect` 边界。与旧全局版不同，概率可随图像位置变化；图像块之间采用双线性插值到像素分辨率。

每个像素 `(y,x)` 的重新模糊定义为 `sum_k p_k(y,x) * G_k(clear)(y,x)`：先对完整图像分别计算三个高斯卷积，再按该位置的概率混合。因此没有对每个裁块独立填充而产生的人工接缝。它是**三核混合的局部近似模型**，不是测得的显微镜空间变化 PSF。

## A1、A2、A3 的统一使用

- A1：`predict_local_from_jit_blur` 将 JiT 模糊输入 `[-1,1]` 转为 `[0,1]` 后，由冻结的局部估计器预测概率图；`LocalDegradationCondition(hidden_size)` 将概率图双线性缩放到 JiT **实际图像 token 网格**，输出 `[B,grid_h*grid_w,hidden_size]` 残差条件。零门控初始化保证接入 A0 权重时初始残差为零。成员 A 决定具体注入位置并验证 token 顺序与图像坐标一致。
- A2：不把概率图注入 JiT；由模糊输入预测概率图，用 `psf_consistency_loss(restored_01, observed_blur_01, probabilities)` 计算重新模糊与输入之间的 Charbonnier 差异。首次对照应冻结估计器；loss 权重与训练由成员 A 设置。
- A3：**同一张**从模糊输入预测的概率图同时用于 token 条件和上述一致性 loss；不得分别估计或在推理时读取清晰目标。

`spatial_psf.py` 在输入为全局恒定概率图时与旧 `reblur_mixture` 等价；`verify_spatial_psf.py` 检查这种等价、已知局部合成参数的重模糊、尺寸和梯度。`verify_local_condition.py` 检查 token 条件尺寸、零门控和同一局部图可同时用于 A1/A3 条件及 A2/A3 loss。

## 训练与验证协议

先只从固定 3DHistech `debug_train.jsonl` 的清晰图合成空间变化的三核混合失焦，保留生成时的每个位置概率作为**合成真值**；按原图组在这 2,000 对内部交叉验证选轮数，再用全部训练图重训。固定 `debug_val.jsonl` 的 300 对不参与选择，只在冻结权重后做一次合成局部真值评价，以及实际配对图的离线重新模糊比较。

合成验证报告局部强度误差、预测图空间标准差、固定轻度与旧全局估计对照、重新模糊误差及样例图。实际配对图没有可靠的局部 PSF 真值：只用其**模糊图**生成预测；配对清晰图在离线评价中用于比较预测参数、旧全局参数、固定轻度参数哪个能更接近模糊输入，并保留成功和失败案例。这不能直接证明恢复模型收益。

## 交接结论

建议成员 A 将此模型作为**实验性局部条件**接入 A1/A3，并把局部 PSF 重模糊函数用于 A2/A3；与固定轻度和旧全局参数保持同一固定验证集的对照。合成验证支持局部参数预测，但真实配对图的离线重模糊优势很小，尚不能断言 JiT 的 PSNR/SSIM/LPIPS 会改善。权重与完整数值见 `LOCAL_A1_A3_RESULTS.md`。
