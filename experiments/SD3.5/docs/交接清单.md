# 队长训练步骤

1. 拉取 `SD3.5` 分支，按 `requirements.txt` 准备 CUDA 环境。
2. 准备数据，使清单中的 `blur_path`、`clear_path` 在 `--repo-root` 下存在。
3. Hugging Face 账号接受 SD3.5 Medium 协议并登录；也可使用本地模型目录。只需要 Transformer 配置和官方 VAE。
4. 先运行 `smoke_test.py`，再运行 `scratch_overfit8.example.json`；两项通过后再启动全量训练。
5. 正式训练使用 `scratch_full.example.json` 和 AdamW，建议 48GB 以上显存，80GB 更稳。
6. 用 `infer_scratch.py` 输出固定 300 张验证图，再调用仓库根目录 `evaluate.py` 计算 PSNR、SSIM、LPIPS。

注意：不使用 ControlNet；不加载 Transformer 预训练权重；VAE 冻结；推理只读取模糊图；不要重新划分数据，也不要把 VAE 重建称为去模糊结果。
