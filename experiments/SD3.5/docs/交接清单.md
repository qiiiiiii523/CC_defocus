# 服务器训练验收清单

1. 同步 SD3.5 分支最新代码，包括本地未提交的修改；仅拉取旧 origin 不会包含这些修复。
2. 按 README 安装 CUDA 版 Torch 2.8.0 和锁定依赖，检查模型配置/VAE 权重可访问。
3. repo-root 使用 `/home/qht/大创/CC_defocus`；生成 full_train/full_val，并在服务器完整解码检查。
4. 运行真实图像 smoke_test，确认前向、反向、optimizer.step、VAE 冻结、条件响应和采样解码，记录显存。
5. 使用 overfit8 配置，检查训练损失与训练图恢复质量；重载 checkpoint 后验证输出。
6. 确认续训和训练周期定义，再启动全量训练。全量配置的 10 epochs 是起点，按验证结果调节。
7. 对固定 debug_val 输出 300 张 PNG，调用根目录 evaluate.py 得到同协议 PSNR/SSIM/LPIPS。

不使用 ControlNet，不加载 Transformer 预训练权重，不把 VAE 重建当作去模糊结果；推理模型只接收模糊图。
